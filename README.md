# cpp_game_dev

C++ game development course on Rebelway focusing on professional game development practices and techniques.

## Overview

This repository contains coursework and projects from the **C++ Coding for Games** course, a comprehensive program covering the fundamentals and advanced concepts of C++ game development. The course explores essential game development patterns, optimization techniques, and real-world game engine architecture.

## Course

Learn more about the course at: [C++ Coding for Games - Rebelway](https://www.rebelway.net/cpp-coding-for-games)
